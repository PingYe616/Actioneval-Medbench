# ActionEval-MedBench

Project page for **ActionEval-MedBench**, a multidimensional video benchmark for evaluating clinical reasoning, safety boundaries, and failure modes of multimodal large language models in rehabilitation.

**Live site:** [https://pingye616.github.io/Actioneval-Medbench/](https://pingye616.github.io/Actioneval-Medbench/)

## Paper

> Systematic benchmarking of evaluation paradigms, safety boundaries, and clinical reasoning gaps for multimodal large language models in rehabilitation

Ping Ye, Yu Li, Mengjian Qu, Xuan Zhang, Jing Liu, Tao Zhu, Jun Zhou  
*Scientific Reports*, 2026

[Paper PDF](./actioneval-medbench-paper.pdf)

## Contents

- `index.html` — academic project page
- `styles.css`, `app.js` — page assets
- `figures/` — paper figures
- `actioneval-medbench-paper.pdf` — accepted manuscript
